# Tango — 関係づけて覚える暗記アプリ

英単語と化学の暗記を、「1問1答の丸暗記」ではなく **関係づけ・双方向化・使って覚える** の3本立てで扱う
Android アプリ（Kotlin / Jetpack Compose）。データはすべて端末内の SQLite に保存され、
通信は一切行いません。

## 設計の柱

### 1. 関係づける（つながり）
ノート同士を**意味のある関係**で結びます。答え合わせの直後、記憶がまだ活性化しているうちに
関連ノートがまとめて表示されます。

| 関係の種類 | 例 |
| --- | --- |
| 同語根 | `perspective` — `conspicuous` — `speculate`（spect / spic「見る」） |
| 対義 / 対比 | `adverse` ↔ `conducive`、希硝酸（NO） ↔ 濃硝酸（NO₂） |
| 混同注意 | `concede` / `precede`、潮解（NaOH）/ 風解（Na₂CO₃·10H₂O） |
| 生成する / から作られる | 接触法 → SO₂ → SO₃ → H₂SO₄ |
| 反応する相手 | SO₂ + 2H₂S → 3S + 2H₂O |

語根・タグ・分類が一致するノートは **関連候補**として自動で提案され、ワンタップで結べます。

さらにデッキ設定で「関係そのものも出題する」を入れると、登録した関係から**問題が自動生成**されます
（「perspective と同語根の語は？」「接触法で生成するものは？」）。新しく入力するものは何もありません。
同じ関係でつながる相手はまとめて1問になり、`生成する` / `から作られる` のように向きで意味が変わる関係は
向きごとに別の問題になります。

### つながり地図
ノートを細胞体、関係を軸索として描く全体図です。選んだノートの結合には信号が流れ、
**明るさはそのノートの「思い出しやすさ」の予測値**なので、暗くなっている一帯がそのまま
忘れかけている範囲になります。未学習のノートは輪郭だけで表示されます。
配置は固定の乱数種から計算するので毎回同じ場所に並び、場所で覚えられます。
「孤立しているノート」で絞り込めば、関係づけの抜けを拾えます。

### 2. 互換する（1ノート → 複数方向のカード）
1つのノートから、選んだ**向き**の数だけカードが作られ、**それぞれ別々にスケジュールされます**。
「英→和は分かるのに和→英が出てこない」を、別の記憶として個別に管理するためです。

- 英単語: 英→和 / **和→英（入力）** / 例文穴埋め / 語源→語 / コロケーション→語 / 例文の和訳→英訳
- 化学・物質: 名称→化学式（入力） / 化学式→名称 / 名称→性質
- 化学・反応: 反応名→反応式（入力） / 反応式→反応名 / 反応名→条件・触媒
- 和文英訳: 日本語文→英訳を書く / 言い換えのポイントだけ確認
- 化学・計算: 計算して答える / 解き方を思い出す

向きはデッキ設定でいつでも増減でき、必要な欄が埋まった時点でカードが自動生成されます。

### 3. 使って覚える
- **入力して答える**カード。採点は表記ゆれを吸収します（大文字小文字、冠詞 `to / a / the`、
  `/` 区切りの別解、化学式の `·`／`・`／`.` や `→`／`->`、下付き数字）。
  1文字違いは「不正解」ではなく**「惜しい」**として区別されます。
- **例文穴埋め（クローズ）**。活用形も伏字にするので `abandon` で `abandoned` を隠せます。
- **和文英訳**。京大英語は[長文2題＋和文英訳＋自由英作文](https://www.haradaeigo.com/kyodai-eisakubun-2026/)という構成で、
  和文英訳は毎年出ます。自動採点は誠実にできないので、英文を書いて提出したあと模範解答と並べ、
  「押さえるべき点」を1項目ずつチェックする**自己採点方式**にしています。チェックした数がそのまま
  評価ボタンの推奨に反映されます。難しいのは語彙ではなく「直訳できない日本語の言い換え」なので、
  その言い換え自体をノートの欄として持たせています。
- **化学の計算**。数値で答え、**許容誤差**の範囲で採点します。`1.2e-3` `1.2×10^-3` `1.2*10^-3`
  全角数字のいずれでも読み取ります。有効数字が模範解答と違えば正解のうえで指摘し、
  **10のべき乗だけずれている答えは「桁が違います」と明示**します（値は合っているので、
  何を直せばよいかがすぐ分かります）。

## 復習アルゴリズム

[FSRS-6](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
（Free Spaced Repetition Scheduler）を実装しています。カードごとに
安定性 S（忘れにくさ）と難易度 D を推定し、想起確率が**目標定着率**（既定 90%）まで
下がる日を次回の出題日とします。数式は
[py-fsrs](https://github.com/open-spaced-repetition/py-fsrs) のリファレンス実装に照合済みで、
`app/src/test/java/com/tango/recall/FsrsTest.kt` が具体的な数値で検証しています。

そのほかの学習設計:

- **交互配置** — ホームの「すべてまとめて学習」はデッキをまたいでカードを混ぜます。
- **兄弟カードの分散** — 同じノートの別方向が連続して出ないよう並べ替えます。
- **新規カードの分散** — 新規は先頭に固めず、復習の間に等間隔で挿入します。
- **1日の新規上限**（デッキごと）— 翌日以降の復習が雪だるま式に増えるのを防ぎます。

## 画面

| 画面 | 内容 |
| --- | --- |
| ホーム | デッキ一覧、新規／学習中／復習の枚数、まとめて学習 |
| 学習 | 出題 → 入力／想起 → 答え合わせ → 4段階評価（各ボタンに次回間隔を表示）→ つながり |
| つながり地図 | 全ノートの関係図。ピンチで拡大、ノードをタップで詳細、デッキで絞り込み |
| ノート編集 | 欄の編集、タグ、生成されるカードの確認、関係の追加・削除、関連候補 |
| 一覧 | 全文検索（語・意味・化学式・タグ） |
| デッキ設定 | 出題する向き、1日の新規上限、TSV/CSV の取り込み・書き出し |
| 学習の状況 | 今日の解答数・正答率・連続日数、7日間の予定、忘れそうな項目、よく間違える項目 |
| 設定 | 目標定着率、1日の復習上限、つながり表示、JSON バックアップ |

## 自分のデータを入れる

- **TSV / CSV 取り込み** — デッキ設定から。1行目が欄名なら見出しとして扱い、
  なければノート型の欄の順に割り当てます。同じ見出し語は重複させず更新します。
  ファイル選択と貼り付けの両方に対応。
- **JSON バックアップ** — デッキ・ノート・関係・**学習の進み具合**をまとめて書き出し／復元。
  機種変更のときはこれを読み込めば続きから学習できます。

初回起動時に、語源でつながる英単語24語、無機化学の物質14件・製法8件、和文英訳5題、化学の計算7題が
**関係づけ済みの例**として入ります。不要なら削除して構いません。

## APK をつくる

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest    # 63 件のユニットテスト
```

`git push` すると GitHub Actions（`.github/workflows/android.yml`）が同じものをビルドし、
APK を artifact として添付します。

**端末へのインストール**: APK を端末に移し、ファイルアプリから開きます。
初回は「不明なアプリのインストール」の許可が必要です。

`assembleRelease` は利便のため debug キーで署名しています。ストア配布や長期運用をする場合は
自前のキーストアに差し替えてください。

## 構成

```
app/src/main/java/com/tango/recall/
  srs/Fsrs.kt              FSRS-6 スケジューラ
  data/Model.kt            ノート型・カードテンプレート（向き）・関係の種類
  data/Db.kt               SQLite スキーマとマッピング
  data/Repository.kt       CRUD・出題キュー・統計
  data/CardContent.kt      カード描画、クローズ生成、入力の採点
  data/ImportExport.kt     JSON バックアップ、TSV/CSV
  data/Seed.kt             初期データ
  ui/screens/ForceLayout.kt  つながり地図の力学配置
  ui/screens/GraphScreen.kt  つながり地図の描画と操作
  ui/                      Compose の画面
```

データベースは追加のみのマイグレーションで上げています（v1 → v2）。
すでに入れてあるアプリを上書きインストールしても、学習の進み具合は失われません。

要件: JDK 17、Android SDK（compileSdk 36）、minSdk 26 (Android 8.0)。
外部の依存は Compose と AndroidX のみで、注釈処理（KSP/Room）は使っていません。
