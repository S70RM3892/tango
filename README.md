# Tango — 関係づけて覚える暗記アプリ

英語（単語・和文英訳・英文和訳）と化学（無機・有機・計算）の暗記を、「1問1答の丸暗記」ではなく
**関係づけ・双方向化・使って覚える** の3本立てで扱う Android アプリ（Kotlin / Jetpack Compose）。
データはすべて端末内の SQLite に保存され、通信は一切行いません。

## 設計の柱

### 1. 関係づける（つながり）
ノート同士を**意味のある関係**で結びます。答え合わせの直後、記憶がまだ活性化しているうちに
関連ノートがまとめて表示されます。

| 関係の種類 | 例 |
| --- | --- |
| 同語根 | `perspective` — `conspicuous` — `speculate`（spect / spic「見る」） |
| 対義 / 対比 | `adverse` ↔ `conducive`、希硝酸（NO） ↔ 濃硝酸（NO₂） |
| 混同注意 | `concede` / `precede`、潮解（NaOH）/ 風解（Na₂CO₃·10H₂O） |
| 生成する / から作られる | 接触法 → SO₂ → SO₃ → H₂SO₄ |
| 反応する相手 | SO₂ + 2H₂S → 3S + 2H₂O |

語根・タグ・分類が一致するノートは **関連候補**として自動で提案され、ワンタップで結べます。

**間違いが関係を育てます。** 入力式の答えを書き間違えたとき、それが**別のノートの答えと一致していたら**、
取り違えた相手を提示します（`precede` と書くべきところで `concede`、希硝酸の式のところに濃硝酸の式、など）。
同じ組を2回まちがえると「混同注意」で自動的につながり、以後どちらを復習しても相手が並んで出てきます。
どこを取り違えるかは人によって違うので、この関係だけは最初から用意しようがありません。

さらにデッキ設定で「関係そのものも出題する」を入れると、登録した関係から**問題が自動生成**されます
（「perspective と同語根の語は？」「接触法で生成するものは？」）。新しく入力するものは何もありません。
同じ関係でつながる相手はまとめて1問になり、`生成する` / `から作られる` のように向きで意味が変わる関係は
向きごとに別の問題になります。

### つながり地図
ノートを細胞体、関係を軸索として描く全体図です。選んだノートの結合には信号が流れ、
**明るさはそのノートの「思い出しやすさ」の予測値**なので、暗くなっている一帯がそのまま
忘れかけている範囲になります。未学習のノートは中が薄い輪郭で表示されます。
配置は固定の乱数種から計算するので毎回同じ場所に並び、場所で覚えられます。

- **時間スライダー**で「1週間後」「1か月後」「試験日」の地図に切り替わります。何もしなければどこが消えるかが見えます
- 2本指で拡大・縮小（指の間の点が固定されます）、1本指で移動、右上の ＋ / － / 全体 ボタンでも操作可
- ノードをタップで詳細、長押しでドラッグして動かせます
- 検索で地図の中を探し、選ぶとそこへ寄ります
- 「周辺だけ」でそのノートから2手以内だけに絞り込み
- 「孤立しているノート」で、関係づけの抜けを拾えます

配置は画面の縦横比に合わせて計算され、ラベルは重なるものを落として読める数だけ描きます。

### 2. 互換する（1ノート → 複数方向のカード）
1つのノートから、選んだ**向き**の数だけカードが作られ、**それぞれ別々にスケジュールされます**。
「英→和は分かるのに和→英が出てこない」を、別の記憶として個別に管理するためです。

- 英単語: 英→和 / **和→英（入力）** / 例文穴埋め / 語源→語 / コロケーション→語 / 例文の和訳→英訳
- 化学・物質: 名称→化学式（入力） / 化学式→名称 / 名称→性質
- 化学・反応: 反応名→反応式（入力） / 反応式→反応名 / 反応名→条件・触媒
- 和文英訳: 日本語文→英訳を書く / 言い換えのポイントだけ確認
- 英文和訳: 英文→和訳を書く / 構文の取り方だけ確認
- 化学・計算: 計算して答える / 解き方を思い出す

向きはデッキ設定でいつでも増減でき、必要な欄が埋まった時点でカードが自動生成されます。

### 3. 使って覚える
- **入力して答える**カード。採点は表記ゆれを吸収します（大文字小文字、冠詞 `to / a / the`、
  `/` 区切りの別解、化学式の `·`／`・`／`.` や `→`／`->`、下付き数字）。
  1文字違いは「不正解」ではなく**「惜しい」**として区別されます。
- **例文穴埋め（クローズ）**。活用形も伏字にするので `abandon` で `abandoned` を隠せます。
- **和文英訳**。京大英語は[長文2題＋和文英訳＋自由英作文](https://www.haradaeigo.com/kyodai-eisakubun-2026/)という構成で、
  和文英訳は毎年出ます。自動採点は誠実にできないので、英文を書いて提出したあと模範解答と並べ、
  「押さえるべき点」を1項目ずつチェックする**自己採点方式**にしています。チェックした数がそのまま
  評価ボタンの推奨に反映されます。難しいのは語彙ではなく「直訳できない日本語の言い換え」なので、
  その言い換え自体をノートの欄として持たせています。
- **英文和訳**。京大英語の中心は下線部和訳で、点差がつくのは語彙ではなく構文の取り方です
  （譲歩・倒置・比較・二重否定）。和文英訳と同じく「押さえる点」を1項目ずつチェックする自己採点にしています。
- **化学の計算**。数値で答え、**許容誤差**の範囲で採点します。`1.2e-3` `1.2×10^-3` `1.2*10^-3`
  全角数字のいずれでも読み取ります。有効数字が模範解答と違えば正解のうえで指摘し、
  **10のべき乗だけずれている答えは「桁が違います」と明示**します（値は合っているので、
  何を直せばよいかがすぐ分かります）。

### 試験日から逆算する
設定で試験日を入れると、スケジュールの基準が「今日が期限か」から
**「その日に覚えていられるか」**に変わります。

- ホームに、試験日時点の予測定着率と、目標を下回る見込みのカード枚数が出ます
- 「試験日に弱い順で復習する」で、**その日いちばん弱くなっているカードから**出題します
- 残り60日を切ると、目標定着率を自動で 97% まで少しずつ引き上げて間隔を詰めます。
  直前に詰め込むのではなく、手前から自然に密度が上がります

Anki では [FSRS Helper](https://github.com/open-spaced-repetition/fsrs4anki-helper) に前倒し・先送りはありますが
試験日駆動ではなく、[締切・試験日の機能は要望として挙がっている段階](https://forums.ankiweb.net/t/deadline-exam-date-feature/56675)です。

## 国公立大学データベース

全国の国立・公立大学を**学科単位**で収録し、日本地図の上で絞り込めます。

- **179 大学 / 1,318 学科 / 入学定員 130,612 人**（募集停止の学科は除外済み）
- 地図の**都道府県をタップ**すると絞り込まれ、地図はその条件での定員に塗り直されます。
  地図が絵であると同時に操作子になっています。ピンチで拡大、沖縄は慣例どおりインセット表示
- **系統の構成バー**（情報／工学／理学／医学…）をタップしても絞り込めます
- 設置（国立・公立）、地方、系統、キーワードで絞り込み、定員・大学名・所在地でソート
- 気になる学科は★で**志望校リスト**に入れて絞り込めます

系統は学部名・学科名から機械的に分類しています（「情報」は 117 学科・73 大学）。
定員は**絞り込み後の学科だけ**を合計するので、たとえば「情報」で絞って定員順に並べると
情報系をどれだけ多く採る大学かの順になります。

**出典**
- 大学データ: [文部科学省「令和7年度 全国大学一覧」](https://www.mext.go.jp/a_menu/koutou/ichiran/mext_00050.html)
- 地図データ: 地球地図日本（国土地理院）。非営利利用では出典明記が条件です。
  営利目的で配布する場合は著作権者への利用報告が別途必要になります

偏差値や入試の配点は含まれていません。偏差値は予備校各社の私有データで、
配点は大学ごとの募集要項にしかないためです。志望校の配点は自分で入力してください。

## 復習アルゴリズム

[FSRS-6](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)
（Free Spaced Repetition Scheduler）を実装しています。カードごとに
安定性 S（忘れにくさ）と難易度 D を推定し、想起確率が**目標定着率**（既定 90%）まで
下がる日を次回の出題日とします。数式は
[py-fsrs](https://github.com/open-spaced-repetition/py-fsrs) のリファレンス実装に照合済みで、
`app/src/test/java/com/tango/recall/FsrsTest.kt` が具体的な数値で検証しています。

そのほかの学習設計:

- **交互配置** — ホームの「すべてまとめて学習」はデッキをまたいでカードを混ぜます。
- **兄弟カードの分散** — 同じノートの別方向が連続して出ないよう並べ替えます。
- **新規カードの分散** — 新規は先頭に固めず、復習の間に等間隔で挿入します。
- **1日の新規上限**（デッキごと）— 翌日以降の復習が雪だるま式に増えるのを防ぎます。
- **直前の解答の取り消し** — 押し間違えた評価を元に戻せます。FSRS には「いまの評価を無かったことに」
  という操作がないので、評価の直前の状態を控えておいて丸ごと書き戻し、記録した復習も1件消します。
- **つまずき続けているカードの検出** — 「もう一度」を5回以上押されたカードを拾い、どの向きで
  落としているかを名指しします。回数を重ねても抜けないので、覚え方を変えるほうが早い場所です。
- **毎日の通知** — 決めた時刻に、その日の残り枚数を知らせます。残っていない日は鳴りません。

## 自分のデータを入れる

- **TSV / CSV 取り込み** — デッキ設定から。1行目が欄名なら見出しとして扱い、
  なければノート型の欄の順に割り当てます。同じ見出し語は重複させず更新します。
  ファイル選択と貼り付けの両方に対応。
- **JSON バックアップ** — デッキ・ノート・関係・**学習の進み具合**に加えて、関係の出題設定・
  試験日・志望校リスト・取り違えの記録までまとめて書き出し／復元。
  機種変更のときはこれを読み込めば続きから学習できます。

## 同梱データ

**224 ノート / 910 カード / 263 の関係**が、**関係づけ済み**で入ります。不要なら削除して構いません。

| 中身 | 件数 |
| --- | --- |
| 英単語（語源18グループ） | 72 語 |
| 化学・物質（無機32・有機29） | 61 件 |
| 化学・反応（無機27・有機30） | 57 件 |
| 化学・計算 | 16 題 |
| 和文英訳 | 12 題 |
| 英文和訳 | 6 題 |

有機化学は「覚える対象」ではなく**つながり**として入れてあります。アルコール → アルデヒド → カルボン酸の
酸化の段階、ニトロベンゼン → アニリン、サリチル酸 → アセチルサリチル酸／サリチル酸メチル、
クメン法 → フェノール＋アセトン。混同しやすい組（アセトン／アセトアルデヒド、マレイン酸／フマル酸、
水酸化アルミニウム／水酸化亜鉛）は「混同注意」で最初から結んであります。

**反応式は機械的に検算しています。** 同梱の化学反応式は、テストが原子の数と電荷を数えて
釣り合いを確認します（`ChemistryDataTest`）。係数の写し間違いはそのまま覚えてしまうため、
人が読んで確かめるのではなく数えて確かめる方式にしています。

データは**パック単位**で入ります。あとからデータを足したバージョンに更新したとき、
すでに使っている端末にも**まだ持っていないパックだけ**が次回起動時に入ります。
同名のデッキ・同じ見出し語のノートがあればそれを使うので、編集や学習の進み具合は上書きされません。

## APK をつくる

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest    # 197 件のユニットテスト
```

`git push` すると GitHub Actions（`.github/workflows/android.yml`）が同じものをビルドし、
APK を artifact として添付します。

### リリースする

`.github/release.txt` にバージョン（例: `v1.5`）を書いて push すると、
`.github/workflows/release.yml` がテストと release ビルドを走らせ、
**タグと GitHub Release を作って APK を添付**します。
リリースノートは `.github/release-notes/<タグ>.md` を置けばそれが使われます。

タグを直接 push するのではなくファイル駆動にしているのは、ブランチを限定した認証では
タグ ref への push が拒否されるためです。同じバージョンのリリースが既にあれば
再ビルドせずに終了するので、間違って押しても安全です。

**端末へのインストール**: APK を端末に移し、ファイルアプリから開きます。
初回は「不明なアプリのインストール」の許可が必要です。

`assembleRelease` は利便のため debug キーで署名しています。ストア配布や長期運用をする場合は
自前のキーストアに差し替えてください。

## 構成

```
app/src/main/java/com/tango/recall/
  srs/Fsrs.kt              FSRS-6 スケジューラ
  data/Model.kt            ノート型・カードテンプレート（向き）・関係の種類
  data/Db.kt               SQLite スキーマとマッピング
  data/Repository.kt       CRUD・出題キュー・統計
  data/CardContent.kt      カード描画、クローズ生成、入力の採点
  data/ImportExport.kt     JSON バックアップ、TSV/CSV
  data/Seed.kt             同梱データ（パックの仕組みと英単語・無機・和文英訳・計算）
  data/SeedOrganic.kt      同梱データ（有機化学）
  data/SeedInorganic.kt    同梱データ（気体の製法・沈殿・錯イオン・金属の製錬）
  data/SeedVocabulary.kt   同梱データ（語源グループの追加分）
  data/SeedPractice.kt     同梱データ（和文英訳・計算の追加分）
  notify/Reminders.kt      毎日の通知とその再設定
  ui/screens/ForceLayout.kt  つながり地図の力学配置
  ui/screens/GraphCamera.kt  地図の拡大・移動の演算（テストで固定）
  ui/screens/GraphFilters.kt 周辺だけ表示・孤立ノート・検索
  ui/screens/GraphScreen.kt  つながり地図の描画と操作
  data/Universities.kt       大学データの読み込み・絞り込み・集計
  ui/screens/JapanMap.kt     日本地図の読み込みと当たり判定
  ui/screens/UniversityScreen.kt  大学データベースの画面
  assets/                    同梱データ（大学一覧・日本地図）
  ui/                      Compose の画面
```

データベースは追加のみのマイグレーションで上げています（v1 → v2 → v3 → v4 → v5）。
すでに入れてあるアプリを上書きインストールしても、学習の進み具合は失われません。

**出題の向きを外しても、カードは消えません。** 一度でも学習したカードは削除ではなく保留になり、
その向きを戻すか、空にした欄を埋め直すと、間隔も履歴もそのまま戻ってきます
（自分で保留したカードは保留のままです）。

要件: JDK 17、Android SDK（compileSdk 36）、minSdk 26 (Android 8.0)。
外部の依存は Compose と AndroidX のみで、注釈処理（KSP/Room）は使っていません。
