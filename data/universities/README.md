# 志望校の配点データ

`assets/universities.tsv`（アプリ内蔵、1318学科・国公立のみ）に追加する配点列。
アプリ本体の assets 差し替えが要るので、取り込みTSVではなく参照用データとして置く。

## 出典と検証

令和9年度 京都大学 募集要項（`S70RM3892/-` リポジトリ `data/r9.txt` に座標抽出済み）。
縦計が 1025 に一致することを検算済み。

- 二次素点 650（国語100 / 数学200 / 理科200 / 英語150）を工学部配点 800 に換算
  （国語×1.0 / 数学×1.25 / 理科×1.25 / 英語×1.333）
- 第1段階選抜は別配点（共テ1000点満点: 国200/地公100/数200/理200/外200/情100）で、
  工学部全体で募集人員の約3.0倍

## 列

| 列 | 意味 |
|---|---|
| kyotsu_total | 共通テスト合計 |
| kyotsu_* | 共通テストの科目別（国語・地歴公民・数学・理科・外国語・情報） |
| niji_total | 二次合計 |
| niji_* | 二次の科目別 |
| sotal | 総合計 |
